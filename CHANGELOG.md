# Changelog

All notable changes to Plot.md are documented here.

## 0.0.5 — 2026-07-29

First public release.

### Added

- Nine safe semantic Markdown directives: decision, flow, matrix, meme, note, hook, visual, reveal, and checkpoint.
- Apple-inspired editorial reading rhythm and a compact Linear-style dark presentation.
- Three local visual chapter layouts: hero, scene, and split.
- Classic, poster, and deadpan meme variants.
- `storyify-markdown` agent Skill for fact-preserving narrative structure.
- `customize-semantic-markdown` agent Skill for safe registry customization.
- Source validation, remote-image blocking, accessible fallback markup, and 30 automated tests.
- A complete biopolymer dataset example with generated visual assets.
